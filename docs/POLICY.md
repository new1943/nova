## Claude Code 16 个核心策略

---

### 1. Query Loop（核心交互循环）

| 方面 | 说明 |
|:---|:---|
| **作用** | 用户输入 → API 调用 → 解析响应 → 执行工具 → 循环 |
| **运转** | ✅ 正常运转 |
| **规则** | max_turns=20，单工具超时60s，工具失败返回错误不中断 |

---

### 2. Token Budget 双阈值

| 方面 | 说明 |
|:---|:---|
| **作用** | 控制 context 使用，超过阈值触发 Compact |
| **运转** | ✅ 正常运转 |
| **规则** | 90% 触发 graceful，>95% 触发 forceful |
