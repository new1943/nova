# AI Agent 技术总览

## Agent 复杂度层级

| 级别 | 名称 | 能力 |
|:---:|:---|:---|
| **L0** | 核心推理引擎 | 纯 LLM，无工具、无记忆，仅依赖预训练知识 |
| **L1** | 连接型问题解决者 | 连接外部工具，搜索、API调用、RAG |
| **L2** | 战略型问题解决者 | 战略规划、上下文工程、主动操作、自我改进 |
| **L3** | 协作式多智能体系统 | 多专家协作、团队分工、编排协调 |

---

## 核心设计模式（Design Patterns）

| 模式 | 描述 | 适用场景 |
|:---|:---|:---|
| **ReAct** | 推理+行动循环（Thought→Action→Observation） | 非确定性、多步骤复杂任务 |
| **Reflection** | 生成→批判→改进 循环 | 质量>速度的场景（代码审查、合同审核） |
| **Tool Use** | 工具调用作为一等公民 | 需要访问外部系统的任务 |
| **Chaining** | 线性串联工作流 | 确定性、结构化流程 |
| **Orchestration** | 多智能体编排协调 | 复杂项目、需要多专业协作 |
| **Planning** | 战略规划模式 | 需要分解目标、动态调整 |

---

## 演进路线

```
LLMs → RAG → Agentic RAG → Agentic AI
```

---

## 架构演进趋势

- **核心趋势**：从单一超级Agent → 多专家协作系统
- **Multi-Agent Systems**：多个专业Agent分工合作（类比人类组织架构）
- **Agentic RAG**：Agent + 检索增强，动态决定何时查什么

---

## 记忆系统设计

### 三层架构（参考 Hermes-Agent）

| 层 | 机制 | 特点 |
|---|---|---|
| **Session Memory** | 对话历史压缩 | LLM摘要，控制token膨胀 |
| **Long-term Memory** | 持久化事实知识 | 跨session检索，可增删改查 |
| **Context Injection** | 标签注入system prompt | 防止模型误认为用户输入 |

## Skill 自迭代策略

- **创建时机**：复杂任务完成、发现有效工作流、用户纠正方法
- **操作方式**：创建/更新/删除 skill，可关联参考文件
- **核心原则**：成功经验固化为可复用技能，减少重复探索
